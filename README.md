# takomak2012-cyber.github.io

Сайт разработчика для приложения **AlkoCalk**.
Хостинг — GitHub Pages, адрес `https://takomak2012-cyber.github.io/`.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная — описание AlkoCalk, восемь режимов, ссылки на загрузку |
| `privacy.html` | Политика конфиденциальности (нужна RuStore и 4PDA) |
| `app-ads.txt` | Список рекламных систем для Яндекса |

## Важно про app-ads.txt

Файл обязан лежать **именно в корне сайта** — `takomak2012-cyber.github.io/app-ads.txt`.
Переносить его в подпапку нельзя: робот Яндекса его не найдёт, и подтверждение
доступа к приложению не пройдёт.

Содержимое сгенерировано интерфейсом Яндекс.РСЯ (Настройки → Общие → app-ads.txt),
идентификатор издателя `304816787`.

## Локальная проверка

```
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`.

## Обновление

```
git add .
git commit -m "описание"
git push
```

GitHub Pages публикует изменения примерно за минуту.
