# takomak2012-cyber.github.io

В этом репозитории лежит **только `app-ads.txt`** — файл со списком
рекламных систем для Яндекса.

## Почему именно здесь

Стандарт IAB и Яндекс требуют, чтобы `app-ads.txt` находился в **корне
домена**:

```
https://takomak2012-cyber.github.io/app-ads.txt
```

Сам сайт приложения опубликован в другом репозитории, `C2H5OH`, и адрес
у него подпапка:

```
https://takomak2012-cyber.github.io/C2H5OH/
```

Если перенести файл вместе со страницами, он окажется в
`.../C2H5OH/app-ads.txt` — подкаталог, который робот Яндекса не примет.
Поэтому файл живёт в корне домена отдельно, а сайт ссылается на него
по абсолютному адресу.

## Содержимое

Файл сгенерирован интерфейсом Яндекс.РСЯ
(Настройки → Общие → app-ads.txt), идентификатор издателя `304816787`.
Обновлять его вручную не нужно — при изменении настроек рекламы
его следует заново скачать из РСЯ и заменить.

`index.html` — короткий редирект на основной сайт, чтобы старая ссылка
не приводила к ошибке 404.
